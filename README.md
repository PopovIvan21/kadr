# Kadr

**Play your console on your PC or Mac at 60 fps.**
Играйте в консоль на ПК или Mac в 60 к/с.

### [⬇ Download / Скачать — latest release](https://github.com/PopovIvan21/kadr/releases/latest)

- 30 → 60 fps frame generation (Mac: Apple frame interpolation; Windows: RIFE)
- HDR+ for SDR games — only real light sources get brighter
- Record and stream to Twitch, YouTube or RTMP without OBS: webcam, mic, Twitch chat, scenes
- Low latency, ultrawide modes, 15 languages
- No accounts, no analytics, no telemetry

Free beta until **December 31, 2026**. Windows 10/11 · macOS 14+ · any USB (UVC) capture card.

## Install

**Windows** — unzip `Kadr-1.0-win.zip` and run `Kadr.exe`. Kadr isn't code-signed yet, so Windows may show “Windows protected your PC”: click **More info → Run anyway**. Frame generation needs a DirectX 12 GPU.

**Mac** — open `Kadr-1.0.dmg` and drag Kadr to Applications. First launch: **System Settings → Privacy & Security → Open Anyway**. Allow **camera** and **microphone** — that's how macOS lets apps read the capture card. Frame generation needs macOS 26 on Apple Silicon.

**PlayStation 5** — turn off HDCP, or the card shows a black screen: **Settings → System → HDMI → Enable HDCP** — off.

## Установка

**Windows** — распакуйте `Kadr-1.0-win.zip` и запустите `Kadr.exe`. Программа пока не подписана, Windows может показать «Система Windows защитила ваш компьютер»: **Подробнее → Выполнить в любом случае**. Для дорисовки кадров нужна видеокарта с DirectX 12.

**Mac** — откройте `Kadr-1.0.dmg` и перетащите Kadr в «Программы». Первый запуск: **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. Разрешите **камеру** и **микрофон** — так macOS даёт доступ к карте захвата. Для дорисовки кадров нужна macOS 26 на Apple Silicon.

**PlayStation 5** — выключите HDCP, иначе будет чёрный экран: **Настройки → Система → HDMI → Включить HDCP** — выкл.
